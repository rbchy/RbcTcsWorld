# ফ্ল্যাশ ডিল (সময়সীমা দেওয়া ছাড়) — REQ-CAT-14

Temu/Amazon-এর মতো: অ্যাডমিন একটি পণ্যে "ডিলের দাম" আর দুটি সময় (শুরু, শেষ) বসায়। ওই সময়ের মধ্যে ক্রেতা কম দামে কেনে; সময় পেরোলে দাম নিজে থেকেই আগের দামে ফিরে যায়।

## নিয়ম
- তিনটি ফিল্ড (ডিলের দাম, শুরু, শেষ) হয় সবই থাকবে, নয়তো কোনোটিই নয়।
- ডিলের দাম সাধারণ দামের চেয়ে কম হতে হবে; শেষ হবে শুরুর পরে; সর্বোচ্চ ৩০ দিন; নতুন ডিল আগেই শেষ হয়ে থাকলে চলবে না (না বদলানো পুরনো ডিল থাকতে পারে)।
- সময় UTC। শুরু অন্তর্ভুক্ত, শেষ বাদ (`[start, end)`)।
- পণ্য আবার সেভ করার সময় ডিল ফিল্ড না পাঠালে ডিল মুছে যায়।

## যেখানে ডিলের দাম চলে
ক্যাটালগ কার্ড, পণ্যের পাতা, কার্ট, অর্ডার লাইন, ইচ্ছেতালিকা — সবই `Product.currentPrice()` ব্যবহার করে, তাই এক জায়গায় ঠিক থাকলে সব জায়গায় ঠিক।

## API
- `GET /api/products/deals` — এখন চলছে এমন ডিল (স্টকে আছে), যেটা আগে শেষ হবে সেটা উপরে; সর্বোচ্চ ১২টি।
- পণ্যের JSON-এ `dealPrice`, `dealStartsAt`, `dealEndsAt`, `dealLive` শুধু ডিল থাকলেই আসে; সাধারণ পণ্যের JSON বদলায়নি।

## ডাটাবেস
`V20__flash_deals.sql` — তিনটি কলাম + CHECK constraint (সব null বা সব সেট, দাম < মূল দাম, শেষ > শুরু) + `dealEndsAt`-এর ইনডেক্স।

## সীমাবদ্ধতা
সাইজ/রঙের কার্ডের "From $…" সারাংশে ডিল ধরা হয় না; ডিল দেখা যায় পণ্যের পাতায়।
