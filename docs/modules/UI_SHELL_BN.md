# নতুন চেহারা: রঙিন মেনু, আইকন, কার্ট ব্যাজ, ফুটার, ক্যালেন্ডার, ড্যাশবোর্ড চার্ট

এই ধাপে কোনো ব্যবসার নিয়ম বদলায়নি, শুধু চেহারা আর ব্যবহার বদলেছে। আগের সব `data-testid` একই আছে, তাই Selenium, Playwright আর Cucumber-এর পুরোনো টেস্টগুলো আগের মতোই চলে।

## কারিগরি সিদ্ধান্ত (interview-এ বলার মতো)

1. **আইকন একটা জায়গা থেকে আসে।** সব বোতামে হাতে আইকন বসাইনি। `icons.jsx`-এ একটা তালিকা আছে: কোন `data-testid` হলে কোন আইকন। যেমন যে বোতামের testid `-search` দিয়ে শেষ, তাতে search আইকন। CSS `::before` আর `mask` দিয়ে আইকন বসে, তাই আইকন লেখার রং নেয়। নতুন পাতায় Search বোতাম বানালে আইকন নিজে থেকেই আসবে।
2. **আইকন শুধু সাজ।** প্রতিটা আইকন `aria-hidden`, বোতামের নাম তার লেখা থেকেই আসে। তাই screen reader আর টেস্ট দুটোই আগের মতো কাজ করে। ফোনে Help আর Cart শুধু আইকন দেখায়, কিন্তু লেখাটা screen reader-এর জন্য থেকে যায়।
3. **কার্ট ব্যাজ নিজে থেকে ঠিক থাকে।** `api.js`-এর response interceptor-এ এই নিয়ম আছে:
   - `/cart` থেকে আসা প্রতিটা উত্তরে `totalQuantity` থাকে। Interceptor সেটা দেখে একটা `cart-count` event পাঠায়।
   - অর্ডার দিলে বা wishlist থেকে কার্টে সরালে `cart-refresh` event যায়, আর ব্যাজ নিজেই আবার পড়ে নেয়।

   কোনো পাতাকে আলাদা করে ব্যাজ আপডেট করতে হয় না।
4. **ক্যালেন্ডার আসল input-এর পাশে বসে।** ভেতরের ঘরটা এখনো `<input type="date">`। তাই টাইপ করা, autofill আর পুরোনো টেস্টের `fill('2026-03-01')` সব আগের মতো চলে। ক্যালেন্ডার একটা বাড়তি সুবিধা মাত্র। কিবোর্ড:
   - ← → ↑ ↓: দিন আর সপ্তাহ বদলায়
   - PageUp / PageDown: মাস বদলায়
   - Home / End: সপ্তাহের শুরু আর শেষ
   - Enter: তারিখ বাছাই
   - Esc: ক্যালেন্ডার বন্ধ

   min আর max-এর বাইরের দিন বাছা যায় না। কুপনের শেষ তারিখ বাছলে সময় 23:59 বসে, যাতে শেষ দিনটা পুরোটা গোনা হয়।
5. **চার্ট লাইব্রেরি ছাড়া।** প্রতিটা চার্ট কয়েকটা SVG আকার দিয়ে বানানো, বাড়তি dependency নেই। প্রতিটার একটা লেখার রূপও আছে: donut-এর পাশে সংখ্যাসহ legend, bar-এর জন্য screen reader-এর লুকানো টেবিল, heat-map-এর প্রতিটা দিনে সংখ্যা। তাই শুধু রং দেখে বুঝতে হয় না, এটা WCAG 1.4.1-এর নিয়ম।
6. **রঙের contrast।** গাঢ় sidebar-এ লেখা 7:1-এর বেশি। heat-map-এর গাঢ় ঘরে সাদা লেখা, হালকা ঘরে কালো লেখা। axe-core দিয়ে dashboard, ক্যালেন্ডার খোলা reports, home আর ফোনের পাতা পরীক্ষা করেছি, serious বা critical কোনো ভুল পাওয়া যায়নি।

| calendar | ক্লিক করে বাছা, কিবোর্ডে চলা (→ ↓ Enter), PageDown, Esc, Today, আর কুপনের 23:59 |

Traceability matrix-এ নতুন requirement **REQ-UI-10 থেকে REQ-UI-14** যোগ হয়েছে। এখন মোট ১১৪টা requirement, সবগুলোর টেস্ট আছে।

## নিজে দেখবেন কীভাবে

```bash
cd frontend && npm run dev        # http://localhost:5173
```

- Admin হিসেবে ঢুকে Dashboard খুলুন: চার্টগুলো দেখবেন।
- Reports-এ গিয়ে From-এর পাশের 📅 চাপুন: ক্যালেন্ডার খুলবে।
- গ্রাহক হিসেবে কার্টে কিছু রাখুন: উপরের Cart আইকনের ব্যাজ বাড়বে।
